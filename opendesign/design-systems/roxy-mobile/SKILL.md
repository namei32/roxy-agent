# Roxy Mobile

使用 tokens/colors_and_type.css 中的 Roxy 浅色角色。蓝色表示主要动作与选择，紫色用于关联模式，颜色需配合文字或形状。
字体沿用 Roboto / Noto Sans SC，由可用系统字体回退。内容使用简洁中文，示例数据明确标注。
触控目标至少 44px；使用 8/12/16px 圆角、留白与低强度 tonal surface。动效为 150–300ms，支持 reduced motion。
复用已打包的 Lucide 图标；图节点使用数据驱动的简单几何图形。不新增生产主题真源。
