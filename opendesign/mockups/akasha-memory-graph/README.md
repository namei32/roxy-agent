# Akasha 记忆图：三屏交互原型

这份独立原型用于评审“找到记忆 → 探索关联 → 核对来源”的手机操作流程。
沿用 Roxy 浅蓝主题，所有节点、对话、时间、版本和权重都是合成样例。
范围依据：[首版功能约定](../../../docs/design/akasha-mobile-memory-graph.md)。

## 预览与操作

从仓库根目录启动静态服务：

```bash
python3 -m http.server 8289 --bind 127.0.0.1 --directory .
```

- [直接打开原型](http://127.0.0.1:8289/opendesign/mockups/akasha-memory-graph/index.html)
- [打开设计目录](http://127.0.0.1:8289/opendesign/)

服务已运行时直接访问链接，不重复启动。此地址用于当前电脑本地预览。

| 屏幕 | 可以实际操作的内容 |
|---|---|
| 图概览 | 搜索“只读”、清空搜索、点选图节点或最近记忆、拖动和缩放、刷新 |
| 局部关联 | 查看一跳邻居、筛选关系类型、选中节点、以选中节点为中心继续展开、查看详情、返回 |
| 节点详情 | 展开原始对话、复制原文、查看关联对象、在图中定位、逐层返回；关联组展示成员 |

建议先搜索“只读”，点开结果，在局部图选择相邻节点，再点“查看详情”。
页面外的三个步骤也可以直接切换屏幕；右侧可切换普通、密集、空图和读取失败场景。
“模拟版本更新”会显示刷新提示；刷新后恢复探索并保留仍存在的示例节点身份。
“重新体验”将原型恢复到普通图第一屏。

## 数据和状态范围

| 样例 | 节点 / 边 | UTF-8 JSON 字节 | 表达的状态 |
|---|---:|---:|---|
| 普通图 V12 | 16 / 22 | 8,628 | 13 个回合与 3 个关联组 |
| 普通图刷新后 | 17 / 24 | 9,188 | 增加一段示例记忆，已有身份保持不变 |
| 密集图 | 100 / 191 | 69,371 | 164 个节点中的有界集合；只在该集合内演示搜索与展开 |
| 空图 | 0 / 0 | 85 | 尚无发布记忆，支持刷新 |
| 读取失败 | 重试成功后使用普通图 | 同普通图 | 加载失败提示与恢复路径 |

数据量是整个合成 fixture 的实际 JSON 大小，未包含未来传输协议的 envelope。
关联组没有伪造的原始对话；强度仅表达关联，不代表事实可信度或因果。
原型使用固定布局辅助比较，支持拖动、缩放和重置，不演示历史检索扩散。

React 状态负责页面、选择、筛选和加载过程。浏览器 localStorage 仅保存
`roxy.akasha.graph-prototype.v1` 下的演示场景、页面、节点身份和示例版本，刷新页面后可以续看。
搜索、图布局和完整返回历史不持久化。剪贴板仅在点击“复制示例记忆”后写入示例文本。
页面不请求真实会话、数据库、模型或插件接口，刷新和错误恢复使用本地计时器模拟。

本轮写入范围为 `opendesign/**`、功能约定和准备记录的原型链接；当前任务是唯一 writer。
设计目录初始化由另一个 worktree 提交后交接，浏览器复核只读源码。
其他效果限于本地构建、回环地址静态服务、浏览器临时 profile 和隔离验证报告。
生产源码、既有测试与 Gate 合同、真实运行目录、手机安装和远端仓库均不在写入范围内。

## 源码与构建

- `src/`：React 组件、图交互和合成数据。
- `styles.css`：三屏和预览框架的响应式布局。
- `app.js`、`app.js.LEGAL.txt`：已打包的浏览器资源及依赖许可，静态服务即可运行。
- `build-info.json`：实际打包依赖版本和输出大小。
- [Roxy 主题快照](../../design-systems/roxy-mobile/README.md)：颜色、字体栈及来源。

修改源码后，从仓库根目录执行：

```bash
node opendesign/mockups/akasha-memory-graph/build.mjs
```

脚本默认使用仓库 `node_modules` 中已有的 React、React DOM、Lucide React 和 esbuild。
也可通过 `--dependencies /absolute/path/to/node_modules` 指定现有依赖目录。
构建产物随原型提交，运行时不加载 CDN、外部字体或在线图标。

## 验证和后续边界

合成数据已检查唯一身份、边端点、一跳过滤闭包、刷新前后身份和初始图预算。
浏览器交互、布局与可访问性结果见[原型验证记录](QA.md)；浏览器模拟不等同于真实 Android 验证。
该原型不证明真实图读取只读、Hub 身份稳定、并发发布一致性、取消或迟到响应隔离。

正式插件集成仍需真实数据探针、发布身份设计、插件接口实现、完整 Gate 和手机实测。
既有镜像漂移及 Inspector 主题测试失败沿用[准备记录](../../../docs/design/akasha-mobile-memory-graph-readiness.md)的归因，原型没有修复这些问题。
回滚仅移除独立原型资产和相关设计链接；无需恢复业务数据库。
