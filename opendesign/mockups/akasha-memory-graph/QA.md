# 三屏原型验证记录

- 日期：2026-09-05。
- 范围：独立静态原型及合成数据；正式插件、真实数据库、Android 设备和后端并发不在本次验证范围内。
- 当前状态：独立原型的构建、数据和浏览器复验通过；完整仓库 Gate 未通过 catalog audit，详见末节。

## 构建和数据检查

使用 [build.mjs](build.mjs) 打包，实际依赖见 [build-info.json](build-info.json)。
运行资源包含 React、React DOM 与 Lucide，无运行时 CDN 依赖。
普通、密集、空图和错误场景分别检查 V12、V13、V99，共 12 组 fixture。
每组均通过唯一节点/边身份、端点完整性、一跳过滤、图预算和关联组来源边界检查。
另核对普通图刷新后既有节点的身份及原文保持不变。

合成数据最大为 100 个节点、191 条边、69,371 字节 JSON，低于初始 128 KiB 预算。
此测量不包含将来的传输 envelope，也不构成真实手机性能结论。

## 浏览器检查

独立复核使用 Chromium 151，桌面视口 1440×1000、1440×900，启用触摸的手机视口 390×844。
实际检查截图和 DOM，并通过点击、输入、拖动及本地剪贴板走通交互。
页面外层和手机内容区各自支持纵向滚动；三个屏幕未发现横向页面溢出。

| 检查 | 最终结果 |

| 搜索、图概览 → 局部关联 → 节点详情、返回 | 通过，含无结果和清空搜索 |
| 密集图中心触摸命中 | 100 / 100 个节点均进入自身身份，连续返回未触发下一屏按钮 |

| 局部图主操作 | 手机与 900 px 高桌面视口中，固定底部摘要和详情按钮可见 |

| 浏览器错误 | 最终复验未发现 console error、pageerror 或 HTTP 错误 |

初轮发现并修改了以下问题：

- 密集图的透明命中区域可能抢占点击；改为投影到屏幕坐标后选择最近节点。
- 局部图详情入口位于折叠区域下方；改为底部固定的选中摘要和操作区。
- 搜索时丢失密集图的范围信息；改为搜索框下常驻范围提示。
- 图缩小时触控区域变小；改用至少 22 px 的屏幕命中半径，版本刷新按钮宽度至少 44 px。
- 缩放工具遮住底部节点；工具移到画布外单独一行。
- 示例回复过短，无法观察展开效果；增加多段合成正文。
- 补充 data favicon，避免无关的 404。
- 连续触摸在 pointerup 换屏后产生 click 穿透；改为在最终 click 中提交选择，拖动与捏合不触发选择。
