# 1005 · Drift 拥有可观察活动与显式成果

- 状态：accepted，实施状态见 [Roxy 的日常与来信](../design/roxy-daily.md)。
- 日期：2026-09-07。
- 依据：维护者讨论 Drift 日常与信箱边界、确认交互设计后要求完整实现；OBJ-002、STA-001/003、PRO-002、HOME-001。

Drift 执行 owner 负责活动开始、实际阶段、结束、中断与可接续关系，并保存模型通过明确工具发布的不可变成果。旧的当前意图和完成通知不足以证明活动仍在运行；展示必须具有真实执行存活依据，失去执行 owner 的旧记录不得继续显示忙碌。

Drift 发布版本化、有界、只读的插件查询。Roxy 小屋通过既有宿主跨插件查询组合日常、emotion 心情和 SessionDB 来信，不直接读取其他插件的私有数据库，不扩展 Android 线协议或迁移 APK。

日常记录活动与成果；信箱记录已经送达的消息。关联使用执行 owner 注入既有 `source_refs` 的活动标识，消息仍在原 outbound 确认成功后提交。观看不等于已读或反馈，活动结束不等于发送成功。

新增记录只增加，成果不可变，当前状态和接续引用可按 owner 协议更新。显示条目上限不授权删除、裁切或迁移持久数据；没有自动历史回填。旧代码可以忽略新增表，回滚保留这些记录。

0038 的导航、组合和原会话身份规则继续适用。本决定补齐已批准日常所需的自主执行事实，Core runtime 仍不识别小屋的场景、文案或插件身份。采用客户端假计时器、持续展示旧意图或直接公开内部推理会违反状态归属与观察准确性，因此不采用。
