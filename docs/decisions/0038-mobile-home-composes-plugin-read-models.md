# 0038 · 移动首页组合插件的只读投影

- 状态：accepted，实施状态见 [Roxy 小屋首页](../design/roxy-home.md)
- 日期：2026-09-07
- 依据：维护者确认沉浸小屋首页与主动来信设计并要求实现；HOME-001、WEBUI-001～006、STA-001、MOB-005。

## 决定

共享移动 WebUI 拥有“小屋 / 对话 / 工具”导航。插件 ESM 可通过可选 `home: {version: 1}` 声明自己的 dashboard 可作为首页；服务端插件目录、线协议和 Android snapshot 不增加小屋专属字段。单候选默认进入，多候选显式选择，无候选时提供对话入口。

宿主给 dashboard 提供可选的 `host` 上下文，包含可打开会话摘要、用户触发的会话/消息导航、插件目录和只读跨插件查询。查询继续经过现有授权、revision、owner、队列与取消通路。旧宿主忽略可选元数据，插件保留普通看板兼容路径。

小屋通过 emotion 公共查询读取其已定义的心情解释；通过独立插件的只读 SessionDB 投影读取已送达主动消息。展示不写入情绪、反馈、消息或已读。进入原会话后的阅读与实际回复继续由原 owner 处理。未同步的精确消息引用可等待投影并明确超时，不以正文、时间或相似度猜测目标。

## 理由与边界

这些需求只需要现有桥能力，采用 WebUI OTA 可以保留已安装 APK、配对、Room、草稿和附件，不将界面改造变成身份迁移。Core Python runtime 不知道小屋或情绪插件身份；房间表现和数据组合属于插件，底层事实仍只有原 owner。旧投递别名只用于当前 Android 同会话精确定位，不能当作 canonical SessionDB message ID。

验证必须分别覆盖真实只读查询、共享 WebUI 与模块集成、现有 bridge 兼容和真机交付，不以设计图或单仓库测试代替运行证据。
